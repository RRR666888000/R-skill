# 从方向到全文

## 开始时内部定清几件事

谁在什么处境下看；这条最想完成什么；现有材料能支持什么；形式与时长限制是什么。已有答案直接沿用；未知项只在影响决定时处理。用户尚无目标受众时，可以从材料提出候选需要，不能假装已经调研确认。

两种起点都可用：从具体需要寻找能交付的内容，或从已有经历、发现、材料寻找与观众的真实关联。后一种不必先塞进固定账号定位；前一种不能为了命题而编造亲历。旧选题失效时，分别检查需要是否变化、材料或方案是否陈旧、入口是否让需要它的人认出关联。

需要扩大关联时，考虑尚未意识到需要、正在比较方案、已经行动但遇到困难等不同阶段。知识、资讯、故事和体验分别兑现相应承诺；不为了扩大受众故意讲得似懂非懂。直接指出痛点可能有用，也可能让人感到被指责或认为与己无关，可比较具体问题、真实旁观故事和希望达成的状态三种入口，不预判哪种必然更有效。

## 方向要能发展成正文

从材料中挑不同的观看任务，而非轮流套标题句式：解决一个选择、见证一次尝试、理解一个反常现象、重新看待一种处境、体验一段情绪或审美等。分清现有素材即可兑现的任务，以及补足关键前提才成立的探索任务。

缺少角度时可选用：细分一个真实优势，回应现有表达遗漏的需要，组合两种互补价值，把既有能力用于新问题，使用可获得的外部场景或人物，或以尝试者身份记录过程。这是备选思路，不需要每次六项全做。

还可以对同一事实更换观察位置：当事人如何选择、旁观者注意到什么、一个物件怎样串起变化、结果使原判断怎样改变。改变的是意义和组织，不是随意改变事实。尚无答案的材料可以围绕一个清楚的问题发展，不必先指定唯一正确结论。

比较方向时，先暂时拿掉开头和风格标签，看正文是否仍有不同的观看问题、组织关系或落点；若内容可原样互换，就合并重复方向，重新寻找差异。差异可以来自同一事实的不同意义，不强求增加新事件。

用户给的是零散片段时，先找共同处境、反复出现的细节或有意义的差异，让主题从材料里浮现；一个声音、物件质感或表达姿态也能成为灵感起点，再寻找它值得展开的关系。目标已清楚时，再按目标组织。已有自然写出的片段，可以先发展再回看观看理由，不要求先填完理论框架。纯口播、单一场地、没有额外演员等限制也是构思条件，不先设计超出条件的大制作。

素材里出现一个动作，只能支持这个动作发生过；不能自动推出本人一贯如此、动作先后、专业水平、原因或效果。可以直接描述已知差异，或提出本条要讨论的问题；想发展成方法教学，需要方法的依据，想发展成经历故事，需要相应经过。条件式候选须把所有尚未确认的前提留作条件，不能只把结局留空。没有足够材料支撑目标时长，就先给可成立的较短版本或指出最关键的补充材料，不用臆造内容撑满。

每个方向用短段落说明：

- 一句方向主张和符合形式的开头方案：口播给示例句，声画内容可给首个动作、画面或声音。
- 谁可能因为什么停留；可能同时吸引哪些偏离目标的动机。
- 后文拿哪两三个不同信息或变化兑现；最后给什么。
- 最重要的取舍、事实缺口或拍摄难度。

没有材料支撑的方向可以标为探索候选，明确需要补什么，不能与立即能拍的方向混为一谈。候选开头用条件说明或待填位置，不能先虚构经历再在末尾补“必须真实”。数量不必凑齐；材料不足时可以给一个能成立的方向及两个明确待补材料的方向，不硬凑三个现成故事。推荐先看能否兑现用户最在意的观看问题，再比较内容潜力与补充成本，不默认最省材料的方向最好。兑现所必需的证据或经过不能降为装饰性的可选细节；缺了就说明关键缺口，或收窄承诺、缩短本条。对有价值的探索方向，点明哪一处关键补充会让它成立、为什么值得补；未确认的答案仍留空。探索方案需说明关键前提及没有该素材时的替代路径，不能把假设写成经历。推荐依据是目标匹配、材料强度和可拍性，不虚构评分，也不无依据断言某方向关注概率最高或留下的人黏性更高。

用户要先选时完成方向比较；用户说“你决定”可代选并展开骨架，已选方向则直接展开。只有明确要完整稿或上下文已在全文模式时才代写。“继续”沿用当前深度，不因 Skill 再增加一次批准。组合方向时先选一个主观看任务，让另一个帮助推进，避免双主线争抢时间。

## 深化是解决内容缺口

确定开头许下什么承诺，正文怎样兑现，结尾完成什么。默认把可扩展骨架交给用户：各段讲哪些具体内容、为什么接在这里、什么变化值得继续，以及用户可补哪类真实细节或判断。已有素材直接放入，不把整篇留成待填问卷；示例句仅帮助理解，不锁定用户口吻。交付前看用户能否据此说出一段：已有事实放在哪、它使前一段的什么问题前进、哪里可加入自己的判断或经历。只给“制造悬念”“情绪升级”不算内容；也不把所有可写的段落都交回待填。格式按任务选择，不必套统一表格或段数。

例如用户只说“收藏了很多教程，却很少真正动手”：可以提出“收藏与动手之间缺了什么”“某次真正用上教程的转折（需有真实经过）”“收藏夹能否当作愿望清单来比较（需本人确认收藏目的）”三个不同观看任务。展开时说明先呈现哪种已知现象、再用什么具体比较改变理解、最后停在什么问题；不能捏造收藏数量、失败经过或已经改善的效果。

可用的推进方式：

| 推进方式 | 什么时候适用 | 缺了什么会失效 |
|---|---|---|
| 信息推进 | 多个互补发现、步骤或比较 | 后面只是重复第一个观点 |
| 事件推进 | 愿望、阻碍、尝试、阶段结果 | 只有时间流水账，没有改变 |
| 共鸣推进 | 细节逐步揭示熟悉处境 | 只报情绪，没有可感的场景 |
| 论证推进 | 问题、依据、解释、结论 | 缺必要前提或例子，跳到断言 |
| 视听体验推进 | 动作、声音、质感及变化 | 只有机械快切，没有体验差异 |

这些可以混合，但不要求每条兼具。正文的新信息可以是事实，也可以是人物的新选择、关系变化或感受的深化。推进方式不等于观看动力：连续修正判断，可以让人想知道答案，也可以让人感到熟悉或好笑；必须指出这份材料具体靠什么使人愿意往下看。“骨架”在本包指可继续扩写的内容顺序，不是要求选定某一课程模型。

组织材料可先选并列或递进：并列让几个互补细节共同形成认识；递进让新问题、条件或行动改变前一阶段的认识。前者检查每项是否有贡献，后者检查变化是否有根据、前后是否接得住。两者可混合，不以数字序号或“本以为……但是……”判断结构，也不为递进补造失败、反方或发现经过。用户明确要全文时内部组织整体并交付所需全文；局部修改不因此强制重做大纲或等待批准。

合并到当前交付审核，不重复跑一轮：如果删掉最吸睛的句子，这条还剩什么价值？本条是否兑现开头的问题或体验承诺？缺口优先通过重组材料、换角度或补一个关键事实解决，不能靠加大情绪和形容词掩盖。

结构不按长片页码、幕数或固定节拍缩放。可以从本条最重要的发现、选择或体验回看前文：哪些前提必须让观众知道，哪些信息应在何时出现，哪里需要留一点反应时间。进行中的事情只确定本条落点；不要求先知道最终结局。

材料单薄时可向细节、原因、选择条件或不同结果的意义继续挖；宏观背景只有能帮助理解这件事才加入。单纯不等于单薄，深化也不等于拔高或增加支线。若精修字句仍无法成立，回到主问题和材料组织检查，而非无限换开头。

需要扩充时，可把问题拆成真实步骤或子问题，把相关材料放在一个有意义的共同主题下，放大已经存在的具体细节，或加入确有依据的反例和变化。按贡献取舍；三点够用就写三点，不为了凑七点或一分钟增加废话。日常内容可用具体观察撑起明线、感受变化形成暗线，也可只用其中一种。

## 结尾服务当次目标

增粉：本条交付成立后，让持续价值可见，例如接下来会记录哪项真实验证，或以后还会处理哪类问题。没有后续计划不强留悬念。

商业：明确观众下一步为什么去直播间、商品页或咨询，且实际承接能兑现。介绍一个具体产品后突然泛喊“什么都能选”，可能使兴趣变散。没有当前活动依据不写限时优惠。

记录、审美、共鸣：可停在动作、发现或呼应，不默认加关注或销售句。

## 修改与停止

用户不满意时先识别落差：方向不想看、正文没东西、语气不合适、事实错误、时长或拍摄不现实，还是受众不匹配。区分反馈指出的问题与提出的解法，例如“加一个反转”可能是在说正文没有变化；按用户意图解决问题，不机械加情节。先从用户不喜欢的成品特征定位问题。例如“像上课”可能需要改变观众跟随的问题和揭示顺序，不能只删掉专业词；“不够有趣”也不自动等于要更激烈。选定后的骨架也要落实调整：哪段承担的问题、内容重点或揭示顺序发生了变化？只在方向介绍里答应调整，正文仍照旧走，不算解决反馈。保持已经成立的事实与用户想保留的部分，解决一两个最大问题。新角度应改变观看任务或内容组织，不只是再给十个近义开头。

完成当前要求的方向、骨架或全文，观看理由与推进清楚、待补素材明确后交付；有不同策略可说明取舍，不宣称存在唯一完美版本。
