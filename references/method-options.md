# 内容策略：选择与展开构思方法

这是从已核对资料改写的操作问题库。发展方向、选择认知入口或增强记忆表达时按问题取用，普通改稿不必全读；不是等通用写作失败后才使用。数字方便查找，不是平台公式或每条必做清单。方向仍须现有事实、当次形式和正文兑现支撑。

## 《借势》的十类入口

| 来源名称 | 转成短视频的构思问题 |
|---|---|
| 借定势 | 观众熟悉的哪种经验或说法，能成为理解新内容的起点？ |
| 借万物 | 哪个真实物件、场景或动作能让这件事被看见、听懂？ |
| 借噪声 | 当前争论暴露了什么未被回答的问题？我有什么依据可以补充？ |
| 借感性 | 哪个具体处境能使感受自然产生，或让抽象利益可感？ |
| 借趋势 | 当下有什么经核实的变化，使这个问题现在值得再讲？ |
| 借杠杆 | 现有资源或真实限制，能否转成有用的观察、实验条件或表达特色？ |
| 借对手 | 面对真实异议，能否公平说清分歧，并用事实、比较或验证回应？ |
| 借智慧 | 有没有更省理解成本的解释、比较方式或可执行判断？ |
| 借偏见 | 哪个既有预期影响了观众理解？需要借它进入、检验还是修正它？ |
| 借视角 | 同一事实换到使用者、执行者、旁观者或另一情境，会显出什么新问题？ |

这些是适配后的问法，不是原文或全部128则的逐条复述。“借偏见”不把刻板印象当事实，“借对手”不要求造敌人，“借趋势”不要求追热点。

## 金枪大叔相关记忆与人物框架

- **大脑墙、金句钉、共鸣网、利他金**：检查听懂的阻力、能复述的主张、共同处境与真实收获。金句由正文支持。
- **聚焦、放大、重复**：确定主问题，让关键差异可感，再在需要的位置呼应。重复应带来新理解或识别。
- **识别、认知、价值观**：能否认出创作者或内容线，理解持续价值，愿意继续接触其表达；无需每条兼具三项。
- **三幕英雄之旅**：已有完整经历时，以出发、阻碍与选择、带着变化回来检查因果。阶段记录可停在真实阶段结果。
- **三种喜剧思路**：语言与行动不一致、表面态度与实际选择不同、熟悉情境被放到意外位置。只在当次需要幽默且材料允许时使用。
- **九浅一深**：系列可兼顾容易进入和深入理解，不采用固定九比一排期，也不降低前面内容的实质价值。

## 安先生的选题与差异化入口

六种可选差异化：**正**，在具体问题上提供真实优势；**反**，回应主流表达忽略的需要；**合**，让两种互补价值共同成立；**跨**，把能力迁移到另一个问题；**借**，利用可获得的人物、场景或公共材料；**弱**，从真实尝试和局限出发展示过程。六者无高低，不需要全用。

不知道差异落在哪里时，可从服务的需要、提供的价值、与观众的表达关系、内容类型、声画形式中找一处有用改变，不必五处都创新。方向可以从已有经验、兴趣、失败教训、替人节约筛选时间或跨领域关联产生；差异不是为了与别人相反。借鉴案例时拆它解决了什么问题、靠什么维持观看，再检查该作用能否在当前材料中成立，不搬作者口吻或表面句式。

已核对课程中的七种选题路径，适配为：

| 路径 | 正文必须交付什么 |
|---|---|
| 新资讯与洞察 | 发生什么、依据在哪、对观众意味着什么；新鲜也可来自新解释 |
| 认知或立场表达 | 具体分歧、理由与条件；“替人说话”不等于揭示事实真相 |
| 情感深处 | 感受所依附的真实细节、矛盾或自我认识；不强制忏悔或公开隐私 |
| 对他人与世界的关注 | 具体观察、评价或实际帮助；人物反应和自身动机不能补造 |
| 场景中的刚需 | 具体处境、真实问题、本条可用的方案；不排斥少见但重要的问题 |
| 精彩的过程 | 过程本身的细节、选择、发现或真实障碍；已知结果仍可有期待 |
| 转化内容 | 当次行动的真实收益与承接；只在商业目标成立时使用 |

七类可以重叠，不是七种必选账号定位。故事、知识直讲、审美体验都可独立成立。

另一版课程列出八类，额外单列**生活展示**：由有意味的日常细节和可感的状态提供观察、参考或体验；不要求富裕、让人羡慕或强烈情绪。七类与八类是课程分类版本的差异，不是两套需要重复执行的流程。

九种观察角度——高效性、时效性、任意性、速判性、持续性、原子性、多轨性、刺激性、意识形态性——适配成九个问题：是否重复；对谁有新意；所需前提是否适合入口；第一印象承诺什么；每段为何继续；信息单位是否清楚；声画怎样分工；是否有自然回应理由；立场和关系是否一致。不据此编造秒数、算法权重或行为概率。

创意课还提供十四个换角度入口：多维解决、跨学科、用新方法看老问题、找盲点、找矛盾、逆向或失败样本、极端假设、时间变化、特殊情境、由小见大、比较与类比迁移、个人经历、多方视角、叙事腔调。与前面重叠时只取一处；假设明确是假设，类比帮助解释但不充当证据，跨学科须查真实关联，多方视角不能编造采访或当事人想法。

钩子课的十三类入口可作为备选：未完成的动作或状态、元素并置、与自身处境相关、挑战已有判断、身份或关系中的分歧、感官体验、围观、真实过程或自我披露、熟悉中的反常、新资讯、节奏、美好瞬间、新奇有趣。类别会重叠，可用于口播、旁白或声画，不要求凑数或先钩子后正文。按当次目标选能兑现的入口，检查理解成本与动机偏差；身份不推定阶层心理，披露须真实自愿，反常不靠编经历，新资讯要核实，感官与围观不代表必然续看或购买。

旧课还有十八类的分类版本，作用重合，不另跑一套。开头可以同时建立相关性、期待和表达感受；增加一个入口只有在不拖延兑现、不妨碍理解时才有意义。让人认出熟悉处境之后，还要给此刻继续看的理由。解释新概念时，用真实行业概念或明确自拟的比喻承接具体问题，不靠陌生术语装成新理论。

## 把方法变成可继续创作的骨架

以下是适配后的操作示意，只有命中当前问题时才用，不要求每条都走完。

| 遇到的问题 | 怎样操作 | 不适用或需要克制的情况 |
|---|---|---|
| 题材明确，但不知道谁会在意（安先生：人群与价值） | 把“讲什么行业”换成“谁在什么处境下关心什么”；比较已有需要和可能被内容唤起的新兴趣，再选入口与兑现 | 具体参照人是创作假设，不当作真实后台画像；不把兴趣培养排成必胜的高级方法 |
| 有事实却没有进入理由（《借势》：定势与视角） | 找受众熟悉的经验，让事实中的差异改变那种预期；说明变化为什么与本条有关 | 没有真实差异时不强造反转；陌生术语不一定是受众熟悉经验 |
| 内容充实却不容易记住（两书：聚焦、放大、重复及记忆表达） | 选一个值得带走的发现，用具体比较让它可感，再决定是否以句子、物件或结构呼应 | 不把全篇压成口号；重复需有情绪、节奏、理解或识别作用，不固定次数 |
| 观众可能只记住事件（《主角》及安先生：个人识别与持续关系） | 在事件中找到创作者真实的判断、选择或尚待验证的问题，使“为什么还看这个人”有内容依据 | 记录、审美或一次性解答不强制自我植入；不编人设、不强制关注句 |

例：素材只有“旧杯子缺口了，我仍在用”。“陪伴十年的杯子”需要年限依据，不能直接写；可以提出“为什么继续用（留用原因待补）”和“缺口与仍在使用的状态”两种方向。前者需要本人补充留用原因，后者可围绕已知缺口与使用状态组织观察。若用户补充“我只是没空买”，就重新判断是否转向生活优先级或轻微荒诞，不把它硬写成怀旧。两种方向都可给骨架；示例不是固定风格。

## 与编剧方法接起来

有事件就检查因果、选择和变化；有论点就检查问题、依据和解释；有日常片段就找差异、反应与呼应；有对白就看每句话想改变什么；有旁白就看它给声画增加什么。需要结构时从落点回看必要前提，需要发现主题时从材料找反复出现的细节。

长片节拍、作者风格和固定人物弧线只在用户明确想尝试时采用。参考有冲突时，在当前目标和材料条件下优先采用安先生与两书的内容策略，导演编剧方法辅助实现；用户明确要电影或戏剧形式时再提高相应方法的使用程度。说明必要取舍，不把全部框架叠成一份稿。
