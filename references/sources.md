# 方法来源与适用边界

版本以SKILL.md元数据与分发清单为准。凌酱Skill面向所有创作者；“凌酱”是项目名称，不要求特定账号、业务、人设、口吻或私人资料。

内容策略参考安先生自媒体课程及金枪大叔《主角》《借势》；导演和编剧方法辅助组织、人物、场景、对白旁白及声画表达。编剧方法研究入口包括 [screenwriting-skills](https://github.com/jtydhr88/screenwriting-skills)，导演框架研究入口包括 [an-video-director](https://github.com/RRR666888000/an-video-director)。此包不捆绑这些仓库、课程、书籍、译文、电影剧本或原始案例；没有其他Skill运行依赖。

把来源方法转为适合当前任务的操作问题：为什么此人此刻会看、已有材料怎样推进、怎样清楚可感、看完得到什么、是否还有再次接触的理由。不同分类重合时不重复执行。结构先行、材料先行和先写再诊断都可；信息、事件、情绪、审美及商业内容均按目标选用。

相关课程的新版结构与运营说明对旧版有替代或修订，后续风格和商业专题按条件补充；本包取适用原则，不把不同年份的课程流程叠成硬规则。七/八类选题、十三/十八类钩子及书中数字口诀是构思入口，不是算法公式、成功保证或固定比例。

作者的个人价值观、课堂练习纪律、历史平台阈值及刻板人群推断不作为普遍规则。真实素材不能为冲突补造身份、经历、引用或结果；用户明确允许虚构的作品保留创作空间。受众审计是由内容信号支持的假设，不是人口画像模型或平台流量预测。

本包公开的是重新组织的方法说明、独立脚本与虚构测试题。原始材料的阅读记录留在建设方；公开测试的输入、输出、首次缺陷和环境边界见仓库tests与docs，不要求使用者取得私人源文。引用的作者、作品和第三方项目不表示授权背书；其原作权利和许可各自独立，本仓库许可不覆盖它们。
