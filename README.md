[English](README.en.md) · [安装说明](docs/INSTALL.md) · [示例提示词](docs/EXAMPLES.md) · [测试与局限](tests/README.md)

## 项目介绍

**凌酱是一套交给 AI Agent 使用的内容创作方法，内置“灵魂问答”子功能。** 你提供素材、目标或一个待解决的问题，它帮助你理清需求，再形成可以继续创作或执行的结果。

- **短视频创作**：从零散想法出发，比较方向、展开骨架、写完整稿、局部改稿或审计受众。
- **灵魂问答**：说“灵魂问答”即可调用作者分享的六段提示词原文，按原文执行。
- **跨 Agent 使用**：提供标准技能目录、技能 ZIP 和完整单文件，按目标 Agent 支持的方式安装或读取。

面向所有短视频创作者，不限定行业、账号、风格或商业模式。“凌酱”是项目名称，使用不需要认识作者，也不需要他的私人资料。

当前方法版本 **0.7.0**。灵魂问答已替换为用户上传文章中的六段原始提示词，逐段保留文字、标点、空格与换行，仅用空行分隔各段；移除先前改编六问及自行添加的采样、交付、复盘与续接扩展。常规视频创作方法保持原有范围。既有P0事实保真失败和历史测试记录仍然保留，本次不宣称已修复。

通常先给两三个真正不同的方向，说明谁可能想看、正文拿什么兑现，再推荐并展开一个具体骨架。你补充经历和自己的话；明确要完整稿时，它也可以写全文。它负责单条视频的文字内容；账号体系、个人IP或工作室规划、批量切片、实际拍剪及成片/数据复盘使用相应的编导、制作或分析流程。普通文章与纯转码不自动触发。

## 让其他 Agent 更新到最新版

把下面这一行复制给**你希望安装或更新凌酱的那个 Agent**：

```text
请按照 https://github.com/RRR666888000/R-skill 首页的更新说明，将当前环境中的凌酱 Skill（lingjiang-content）更新到最新版；未安装则安装，保留我的自定义修改，完成后核对版本、完整文件和“灵魂问答”调用，并告诉我实际更新位置及验证结果。
```

这里的“更新”指把该 Agent 环境中的已安装技能更新到本仓库最新版本，包括内置的“灵魂问答”。如需修改技能的设计或新增功能，请另行说明具体需求。

### 给 Agent 的更新说明

1. 读取本 README 和 [安装说明](docs/INSTALL.md)，确认当前宿主实际支持的技能安装方式、作用域和已有安装位置。文档中的路径是示例，以当前宿主的有效规则为准。
2. 获取本仓库默认分支的最新版本。技能包、校验清单与参考文件应取自同一个提交，避免混用不同版本。目录安装使用完整技能包；仅能读取附件的环境使用完整单文件，并明确其只是文本调用。
3. 已安装时先备份，识别并保留用户的自定义修改。将官方更新与本地修改合并；无法判断的冲突保留原件并报告，不静默覆盖。未安装时按宿主规则安装，不改其他技能或全局指令。
4. 更新完整技能目录，包含 `SKILL.md`、`references/`、`scripts/`、`agents/` 和 `LICENSE`，不能只替换入口文件。升级到0.7.0时，移除已退役的官方文件 `references/soul-delivery.md` 和 `references/soul-research.md`；其中有自定义修改时先另存备份。原始发布包按 `dist/manifest.json` 校验；合并自定义修改后，单独报告与发布包的差异。
5. 读回检查版本、文件完整性与 `references/soul-questions.md` 中的六段作者原文。检查宿主是否发现技能；能调用时，确认“灵魂问答”入口读取该原文文件，不再加载旧版扩展。将文件核对与实际业务效果验证分别报告。
6. 报告实际安装位置、更新前后版本、保留的自定义修改、校验与调用结果。需要刷新或新会话时明确说明；受网络、权限或宿主能力限制时报告具体未完成项。只能操作云端环境时，不声称已更新用户电脑；下载完成、安装完成、宿主发现与实际调用分别核实。

## 灵魂问答子功能

直接说“灵魂问答”，凌酱会读取[作者六段提示词原文](references/soul-questions.md)，按原文执行。提示词来自用户提供的《（万字长文）小红书获客指南（一）· 调研篇》文本，作者为 aix阿乐（X @Leepriest1990）。

原文文件不加入改写、补充问题或自定义流程。0.7.0替换此前的改编版本，移除问后增强、采样、续接和复盘扩展。六段原文包含在目录版、ZIP和完整单文件中。常规视频功能继续使用原有入口。

[0.7.0核对记录](tests/soul-070/README.md)检查原文与分发内容一致性；此前0.5.3—0.6.1的灵魂问答测试属于旧版历史，不代表当前原文版行为。

## 人类怎么下载

第一次接触 Skill？它是交给 AI 的一套工作方法，你仍在自己的 AI 对话里提供素材、看方向和改稿。请选择适合自己的方式：

| 你的情况 | 下载什么 | 下载后怎么用 |
|---|---|---|
| 想先试试，不安装 | [通用单文件 Markdown](https://raw.githubusercontent.com/RRR666888000/R-skill/main/dist/lingjiang-content.md) | 保存为 `.md`，上传给能读完整附件的 AI，再发送下面的试用请求 |
| 产品支持“上传技能包” | [技能 ZIP](https://raw.githubusercontent.com/RRR666888000/R-skill/main/dist/lingjiang-content.zip) | 在产品的技能管理里导入 ZIP，再确认启用 |
| 使用 Codex、Claude Code 等本地 Agent | [技能 ZIP](https://raw.githubusercontent.com/RRR666888000/R-skill/main/dist/lingjiang-content.zip) | 按[安装说明](docs/INSTALL.md)解压完整内容到当前宿主的技能目录 |
| 想查看或修改源码 | [完整仓库 ZIP](https://github.com/RRR666888000/R-skill/archive/refs/heads/main.zip) | 解压后阅读 README；这是源码包，不是直接导入的技能包 |

单文件下载后如果显示一屏文字，使用浏览器“另存为”保存为 `.md`，或复制完整内容。不要只上传文件名或截图。技能 ZIP 内的入口直接是 `SKILL.md`；目录安装时保留 `references/`、`scripts/`、`agents/` 和 `LICENSE`，文件夹仍命名为 `lingjiang-content`，不是仓库名 `R-skill`。

上传单文件或安装后，可以发：

> 请使用凌酱 Skill。我的已知素材是【材料】，想做【时长、形式】的视频，目标是【希望观众得到什么】。比较几个不同方向，推荐一个展开骨架，我自己补充内容。缺少的经历不要编。

## Agent 怎么下载并安装

如果你的 Agent 可以联网并操作当前环境的文件，**复制下面整段发给它**即可。无需你自己执行命令。

```text
请从下面的公开仓库下载并安装 lingjiang-content（凌酱 Skill）：
仓库：https://github.com/RRR666888000/R-skill
安装说明：https://raw.githubusercontent.com/RRR666888000/R-skill/main/docs/INSTALL.md
技能包：https://raw.githubusercontent.com/RRR666888000/R-skill/main/dist/lingjiang-content.zip
校验清单：https://raw.githubusercontent.com/RRR666888000/R-skill/main/dist/manifest.json
无原生技能入口时使用的完整单文件：
https://raw.githubusercontent.com/RRR666888000/R-skill/main/dist/lingjiang-content.md

先读取安装说明，确认你当前宿主支持的技能目录和安装作用域。
下载技能包与校验清单，核对ZIP的SHA-256及解压后的skill_files。
将完整内容安装到名为lingjiang-content的目录，确保SKILL.md直接位于该目录下。
已有同名版本时先备份并保留我的修改，不改其他技能或全局指令。
安装后报告实际路径、版本、文件校验结果，以及宿主是否发现该技能。
能在当前环境调用时，用虚构素材验证一次；需要刷新或新开会话时如实说明。
若只能操作云端/沙箱，不要声称已经安装到我的电脑。
若没有原生Skill入口，读取完整单文件用于本次对话，并说明是文本调用。
若不能联网或写文件，明确具体缺项，告诉我需要下载或放置哪个文件。
不要仅给我安装教程，也不要把下载完成说成安装、发现和调用都已完成。
```

Agent 可通过上面的公开 HTTPS 地址获取文件，也可用 Git 下载源码：`git clone https://github.com/RRR666888000/R-skill.git`。克隆只得到源码；接着仍需按宿主规则安装，不能把源码目录自动视为已启用技能。公开下载不需要本仓库专属密钥；网络、文件权限和原生 Skill 支持由 Agent 所在环境决定。

原生安装后的调用：Codex 可用 `$lingjiang-content`，Claude Code 可用 `/lingjiang-content`；其他宿主以[安装说明](docs/INSTALL.md)及其实际支持为准。没有原生入口但能读取完整文件的 Agent，也可以按单文件方式试用。

## 第一次可以这样试

不需要准备复杂资料，先用这段虚构练习：

> 这是虚构练习，不是我的真实经历：有人连续三天拍同一扇窗，第一天晴天，后两天下雨。用凌酱Skill，只给两个短视频文字方向，各写观看理由和主要取舍，先不要展开骨架。

预期得到的是两个讲法及其差异，例如“同一位置的变化”和“重复观察的意义”；这是可能的方向举例，不是固定答案。然后可以接着说：

1. “选第二个，展开骨架。我还没定时长和形式，先别替我决定。”
2. “现在定为45秒口播，按这个骨架写完整稿，允许虚构，估计朗读时长。”
3. “只改第一句，让它更自然，不重贴正文。”

真实创作时，把练习换成你确认的素材，并说明哪些是事实、哪些只是想法。你也可以直接要全文；分步只是方便比较和修改。说“继续”会沿用当前交付范围，要进入全文时请明确说“写完整稿”。

## 它实际帮你做什么

| 你现在的需要 | 输出 |
|---|---|
| 只有零散材料 | 不同观看任务、主要取舍、能成立的方向与缺项 |
| 已选一个方向 | 各段具体讲什么、为什么接在这里、适合补什么材料 |
| 想到新事实 | 判断是否改变方向与结构，保留仍成立的事实 |
| 明确要全文 | 符合形式的稿件及可复算的估计时长；不逐段等确认 |
| 只改首句/某段 | 修改指定范围与必要衔接 |
| 只想审计 | 从实际内容信号推测停留、续看、看完与关注理由 |

不同方向需要不同的正文兑现，不能只是十个近义开头。默认不模仿作者或用户旧稿；你明确指定自己的样稿时，可以参考其表达特征。无口播作品不强加台词；没有变现计划也能开始。方法要求材料不足时明确缺项，不靠假经历撑满时长；实际模型仍可能不遵守，见下方实测边界。

## 能力边界

这是一套创作方法，不能预测流量或保证爆款。受众分析是有依据的假设，无法从文案准确推出年龄、收入或留存百分比。事实是否真实、片段实际怎样、成片节奏和最终发布效果仍需相应材料与验证。

跨Agent意味着相同的标准目录和文本方法可被支持它们的宿主读取；不意味着所有模型表现相同、所有产品已实测或每台电脑都已安装。当前Claude Code配置的`kimi-k2.6`已能原生调用，但稀少真实素材的多轮输出仍补造细节、心理或错误判断方法，尚未通过该项保真验收。请逐句核对要直接采用的事实及专业判断。Codex的有限回归结果不能证明其他模型同样可靠；所有失败首稿一并保留。见[测试记录](tests/README.md)。

## 文件怎么选

- `SKILL.md` + `references/`：标准目录版，按问题读取，适合原生支持Skill或能读目录的Agent。
- `dist/lingjiang-content.zip`：同一目录版的导入包。
- `dist/lingjiang-content.md`：完整单文件，适合附件或粘贴。整份输入会占用上下文；“按需取用”不会减少已经上传的文字量。
- `agents/openai.yaml`：可选Codex显示信息，其他Agent可忽略。
- `scripts/`：构建与校验工具，以及可选的确定性中文口播时长估算；普通创作不需要Python、MCP、密钥或其他Skill。英文或大量中英混排不能直接套用中文字符语速，优先实录或传入自行校准的口播单位数。
