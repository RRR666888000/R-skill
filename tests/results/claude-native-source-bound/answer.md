收到。先确认本次可用事实：一张照片 → 一只旧水杯 → 杯口有缺口 → 主人是谁：不知道 → 是否还在用：不知道。就这些，全篇只围绕它们组织。

## 两个方向

**方向A：观察 vs. 想象——一张能当证据用的照片**
- 主张：这张照片恰好是一面"照妖镜"——缺口是观察，其余全是想象。给观众一个小到能带走的分辨规则。
- 谁停留：喜欢想清楚问题的人；"我看到的到底是真的吗"这种处境人人有。可能偏离的动机：纯猎奇老物件的人会失望。
- 兑现：先让观众自己代入"你会想到什么"→ 逐一指认哪些能指回照片、哪些不能 → 给规则 → 落在一个可做的动作。
- 代价/风险：偏认知，情绪浓度低，要靠句子的干净撑住。

**方向B：未知是旧物最勾人的地方**
- 主张：这只杯子的缺口是唯一的事实，而"主人是谁、还在不在用"这两个空白，正好是我们想象力涌进去的地方——让人移不开眼的常不是旧物本身，是我们填进去的东西。
- 谁停留：情绪、审美向观众；安静沉思类内容。可能偏离：容易被当成怀旧故事，而怀旧故事需要杯子的历史——这正是我们没有的。
- 兑现：停留在"空白"这个感受上，靠问题和留白推进。
- 代价/风险：45秒纯口播的抒情方向，通常需要创作者自己的经历或感受作支点；本次没有，硬写会滑向替杯子编身世。

**推荐A。** 材料完全够用、零补充成本；纯口播不依赖画面；45秒恰好够讲一个"现象—分辨—带走"的小闭环。B不是不好，是缺支点——除非你之后愿意补"我为什么存这张照片"，那可以再往B靠。

## 方向A骨架（45秒 ≈ 170–220字，按220–300字/分钟估，实录后校准）

**① 开头 · 代入（约12秒 / 45–60字）**
用提问把观众放进同一张照片前，只列可能性，不断言任何杯子历史。
- 示例句："看到一只陌生旧杯子的照片，杯口还有缺口——你会想到什么？用了多少年？主人是谁？是不是已经被扔了？"
- 这里每一个问题都是开放问句，不是事实，安全。

**② 分辨 · 全片核心（约15秒 / 60字）**
- 示例句："照片里能确认的，只有两样：这是一只旧杯子，杯口有缺口。剩下的——摔过、用了很多年、主人不要它了——都不在照片里。"
- 接规则句（全片唯一金句）："能指回照片的，是观察；指不回去的，是想象。"

**③ 落点 · 为什么是旧物（约12秒 / 50字）**
- 示例句："旧物最容易骗人的地方就在这：缺口是真的，可缺口背后的故事，是我们自己填的。这只杯子主人是谁、还在不在用——都没人知道，而这两个不知道，正好是要练习的地方。"
- 注意：把"未知"从缺陷转成练习场，呼应主题。

**④ 结尾 · 可带走的动作（约6秒 / 25字）**
- 示例句："下次看到旧物，先停一下：这是我看见的，还是我想出来的？"
- 停在开放动作，不加关注句、不替观众回答。

**推进方式**：论证推进——问题 → 区分 → 规则 → 动作，每段都改变理解，不重复。

**可补素材（可选，非必需）**：你为什么留着这张照片——如果有真实原因（哪怕"随手存的"），可以塞进①开头一句，把"陌生照片"变成有来处的照片，代入更强；不补也完全成立。

**审核**：开头承诺"分辨观察和想象"→ ②兑现规则 → ④留下可复述的动作，删掉金句后仍有一条完整区分练习。事实断言全部能指回已确认材料；时长靠字数为界，建议试读一遍再压。
