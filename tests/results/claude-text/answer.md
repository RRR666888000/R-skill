# 两个方向

**方向一：从“这个缺口”进入——具体的观察现场**
- 主张：面对一件陌生旧物，我们能确认的其实只有非常少的信息；缺口、磨损、污渍是观察，"主人很节俭""用了十年"是想象。用照片里这一个杯子，演示一次"看见→想补充"的心智过程。
- 谁能停留：对日常细节敏感、喜欢琢磨"我怎么知道一件事"的观众；动机是好奇和方法，而不是故事。
- 兑现：先只许自己说"杯口有缺口"这类可直接看见的话，再展示大脑自动补出来的部分（谁用过、用多久、为什么留着），最后给一个简单可用的区分标准。
- 代价：没有人物和情节，靠语言和思考过程本身推进；45秒内必须克制，不能讲成知识课。

**方向二：从"我们为什么忍不住编故事"进入——想象的机制**
- 主张：缺口之所以诱人，是因为它像一个未完成的句子；人面对不完整的信息会本能地补全。聊的不是杯子，是这种冲动本身。
- 谁能停留：喜欢心理、认知类轻内容的观众；动机是"这说的就是我"。
- 兑现：指出缺口的"未完成感"，给一个自己也立刻补了故事的诚实例子（必须是真实发生的，需你确认），再落到：想象不可耻，但要知道自己什么时候从看变成了猜。
- 代价：核心论证依赖一个你自己的真实反应；如果那个"忍不住想"的瞬间没有真实发生，整条的诚实感会塌。这是关键待补材料。

**推荐方向一。** 理由：它完全建立在已确认材料上（一张照片、杯口有缺口、主人是谁不知道），不依赖任何待补的个人经历；且"观察 vs 想象"的区分本身就可以用杯子当场演示，45秒装得下。方向二如果后续你愿意补一个真实瞬间，可以发展成下一条。

# 推荐骨架：方向一（45秒，约180–210字口播）

**入口（约5秒）｜承诺：只用一个杯子，演示一次观察和想象的区别**
- 首个动作就是"看"：给出已确认事实——"照片里是一只陌生的旧水杯，杯口有一个缺口。"
- 关键限定要早说："主人是谁、还在不在用，我不知道。"这句话同时是事实边界，也是本条的悬念来源：接下来全靠这个"不知道"。

**中段一（约12秒）｜观察层：只许说看得见的**
- 只做一件事：逼自己（也逼观众）停留在可直接确认的描述——杯口有缺口，杯身有使用痕迹。可以有一句示例："这些是观察，照片替我作证。"
- 推进方式：信息推进的第一层，给后面"想象"腾出对照面。

**中段二（约15秒）｜想象层：大脑自动启动的部分**
- 转折点在"但是"之后："但是看到缺口，我脑子里已经开始补了——是谁磕的？用了几年？为什么没扔？"
- 这里必须说成"我在想什么"，不能说成"发生了什么"。这句边界就是全条的核心论点：这些想法很自然，但它们是想象，不是看见。
- 可留一个气口，让观众意识到自己也在这样做。

**落点（约10秒）｜给一个能带走的区分标准**
- 收口在可操作的一句话，方向是：**"能被照片验证的，是观察；不能被验证的，再合理也是想象。"**
- 可以再加半句把杯子收进来："缺口在照片里，'主人很念旧'在我脑子里。"——这句把抽象标准落回具体物件，帮助记忆。

**结尾（约3秒）｜呼应，不升华**
- 停在杯子或停在"下次看旧物时，可以先问自己：这是我看见的，还是我猜的？"不做关注请求，本条目标是知识理解和共鸣，符合目标的结尾就是一句可带走的提问。

**写作时的红线**（展开全文时遵守）：
- 不出现"用了十年""主人很节俭""杯子有故事"等断言；即使作为"我想象的"例子，也保持条件句式——"我想到的是……"而非"这一定是……"。
- 年限、材质、来历一概不写，除非照片本身可确认且你确认。
- 示例句供理解结构用，成稿时按你自己的说法习惯替换。

**短审核**：开头的"不知道主人是谁"既是事实也是钩子——观众会想知道"不知道还怎么聊"，答案正是本条的观看任务，承接成立。最大风险是中段二滑成对杯子编故事；只要守住"我的想法≠事实"的句式，想象层反而会成为全条最共感的部分。素材缺口：无硬性缺口，可立即写全文。
