## 如何判断

- **事实**：主语、所属关系、时间、来源、心理反应与结果均有材料支持；假设不能冒充自述。
- **方向与内容**：方向有不同观看任务及具体兑现；材料不够时明确，不靠标题句式或假经历凑数量、时长。
- **范围**：骨架不擅自变全文、只审计不改写、局部修改不扩写；新事实只更新被推翻的部分。
- **表达自由**：本人样稿须明确指定，允许不同立场；无口播不加台词，虚构作品按已允许的虚构范围创作。
- **受众与效果**：推理有具体信号和其他可能解释，不编人口画像、百分比、法律胜负或实际成片成绩。

### 同一冻结题组的Codex子Agent输出

- [H1](results/codex-H1.md)：未把三天推广为每日习惯，未补动机，给两方向和口播骨架。
- [H2](results/codex-H2.md)：保留“看着”限定，不把一次差异判为纸张原因，方法没有跳过未控条件。
- [H3](results/codex-H3.md)：保留朋友转述，不补袋中物、住户身份或亲历；“内容还空着”是信息空白比喻，可能被误听成袋子空，建议实际成稿写“袋子里装什么仍不知道”。
- [H4](results/codex-H4.md)：按许可自由虚构并交全文，无健康功效；时长约数尚未实演。

这组未发现前述硬性事实失败，但H3有表达歧义、全部均无实拍效果数据。不能用Codex的有限样本抵消Kimi失败。

最终打包前另修正两处方法示例：把预设“满足替代行动”“舍不得换”改为开放问题/待补原因；这是公开审计发现的示例前提修复，未宣称由此已修复任何模型行为。完整包文件SHA见dist/manifest.json，不只看入口SHA。此后没有继续重试直到得到好答案。
