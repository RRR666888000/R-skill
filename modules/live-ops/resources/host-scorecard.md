# 60 分主播评分表

> 评分是训练工具，不是行业标准。每一项都要落到具体句子/时间点。

## 一、60 分三项（缺一不可）

| 项目 | 合格标准 | 证据句/时间点 | 得分（0/1） |
|---|---|---|---|
| 分享感 | 像正常人说话，不像机器人/背稿/直播腔 |  |  |
| 素品力 | 30–40 秒内出现一次 FB（产品有什么 + 消费者什么好处） |  |  |
| 正能量 | 有热情/职业操守，不半死不活；不等于音量大小 |  |  |

**判定**：三项齐 = 60 分；缺一 = 未达标；0 分 = 口水话 + 无素品 + 无正能量。

## 二、进阶项

| 项目 | 标准 | 证据 | 得分 |
|---|---|---|---|
| 逻辑感 | 每句话指向一个行为；PFABES 顺序正确 |  |  |
| 社会经历 | 有真实案例/阅历支撑（课程未给训练法） |  |  |

## 三、七大核心三观自检

- [ ] 有分享感
- [ ] 正能量
- [ ] 我为你好（先共情，再解决麻烦）
- [ ] 我永远是对的（底气，不是虚构事实）
- [ ] 我的产品最牛（主观底气，不是虚假宣传）
- [ ] 我不尴尬（说错话/被黑粉攻击也镇定）
- [ ] 不改变（不被公屏带节奏）

## 四、不自信三症

- [ ] 眼神飘动/眼神空
- [ ] 肢体动作过多、不大方
- [ ] 反复结巴、用“等一下”拖时间

## 五、训练项

1. 分享感：穿透法 / 和世界万物说话 / 想象镜头后是人。
2. 素品力：30–40 秒 FB；15 分钟回放扒逐字稿，量最长空档。
3. 正能量：先解决职业操守/热爱问题；正能量可以演绎，但不能虚假。
4. 逻辑感：PFABES 话术表 + 读稿 10–40 遍。
