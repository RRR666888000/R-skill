# 《直播电商基础课》术语表（作者用法）

> 定义按课程原意整理；与字典/常识不同的地方单独标注。转写稿有同音错字，别名列在括号里。

## 一、产品语言

| 术语 | 作者的定义 | 与常识的差异 |
|---|---|---|
| 需求 | 消费者想要达到的状态（夏天通勤清爽体面） | 不是「市场需要」，而是具体消费者的向往状态 |
| 痛点 | 需求的反面，消费者害怕发生的事（后背湿、抬手有味道） | 与需求成对出现，不是泛泛的「难点」 |
| 属性 | 产品客观存在的一切参数与事实（聚酯纤维、凉感面料、二本针领口） | 不附带消费者好处 |
| 功能 | 产品能带来什么（吸湿排汗、3 秒速干、穿着舒服） | 比属性更靠近结果，但仍不是消费者利益 |
| 卖点 | 商家从属性中主动挑选出来、认为重要的那一部分 | 是「选择」，不是全部属性 |
| 价值 | 卖点 + 卖点对应的、消费者能感知的好处（不粘身体） | 关键在「消费者能感知」，不是功能罗列 |
| 买点 | 价值 + 购买动机（今天拍立减 30、前 500 送冰袖） | 是「现在为什么买」，不是「为什么需要」 |
| 购买动机 | 催化剂型六项（价格/保障/紧迫/信任/从众/急需）+ 理由型两项（痛点/价值） | 作者实操上要求先记催化剂型 |
| 素品 | 讲产品有什么、能给消费者带来什么，即 FB 话术 | 转写常误写为「速评/素屏/竖屏/碎屏」 |
| 逼单 | 在信任峰值后施加成交催化（S） | 不是求人、不是欺骗；心态是「我要你买」 |

## 二、人群

| 术语 | 作者的定义 | 与常识的差异 |
|---|---|---|
| 八大人群 | 抖音策略人群：Z 世代、新锐白领、精致妈妈、小镇青年、资深中产、都市蓝领、都市银发、小镇中老年 | 按城市 × 年龄 × 消费力切分，不是性格分类 |
| Z 世代 | 三线及以上城市、25 岁以下年轻群体 | 不是所有年轻人；小镇年轻人归小镇青年 |
| 新锐白领 | 三线及以上、25–35 岁白领 | 未婚未育女性通常归此类；已婚已育/备孕归精致妈妈 |
| 精致妈妈 | 三线及以上、25–35 岁或已生育的白领女性，消费中高以上 | 严格说是新锐白领的子集 |
| 小镇青年 | 四线及以下、35 岁以下青年 | 审美受新锐白领影响，价格敏感但愿意为快乐买单 |
| 资深中产 | 三线及以上、36–50 岁、消费中高 | 不是新锐白领的必经之路；消费力掉了会掉出八大人群 |
| 都市蓝领 | 三线及以上、25–35 岁、消费中等偏下 | 按消费力不按职业/工资划分 |
| 都市银发 | 三线及以上、50 岁以上 | 不按消费力划分；新锐白领/都市蓝领老了会进入 |
| 小镇中老年 | 四线及以下、35 岁以上 | 熟人社会；价格敏感度最高 |
| 策略人群 | 平台用于投放/运营的人群标签 | 不是个体决定论，也不是全世界 |

## 三、场景与内容

| 术语 | 作者的定义 | 与常识的差异 |
|---|---|---|
| 人货场 | 人（长相/气质/穿着）、货（外观/预设受众/使用）、场（使用/背书场景）的匹配 | 不只属于直播，短视频同样适用 |
| 背书场景 | 工厂、门店、科学性、权威性四类可信场景 | 不是「背景好看」，而是提供信任证据 |
| 可呈现性 | 产品特点能否被镜头一秒看懂；呈现价值而非卖点 | 不是「拍得精美」，而是「看得懂且与我有关」 |
| 28 理论 | 一个视频一个主定位，主定位占 70–80%，其余占 20–30% | 不是时间分配，而是心智占比 |
| 走马观花 | 客观型：卖点堆砌；感知型：论据接不回主定位 | 后者更隐蔽，商家自己往往看不见 |
| 三段式 | 开头 + 产品呈现 + 引导行动 | 可简化为两段式/一段式 |
| 定位 | 消费者心智中的一个词/标签 | 不是「产品有什么」，而是「消费者记住什么」 |

## 四、主播与话术

| 术语 | 作者的定义 | 与常识的差异 |
|---|---|---|
| 60 分主播 | 分享感 + 素品力 + 正能量，能把流量接住 | 不是「会喊会演」 |
| 分享感 | 像正常人说话，不像机器人/背稿/直播腔 | 也叫对话感 |
| 素品力 | 持续讲 FB：产品有什么 + 消费者什么好处 | 30–40 秒内必须出现一次 |
| 正能量 | 热爱行业、热心解决问题；不等于音量大小 | 沉稳、幽默、老实本分都可以是正能量 |
| 逻辑感 | 每句话指向一个行为，PFABES 顺序正确 | 80 分项，不是 60 分门槛 |
| 七大三观 | 分享感、正能量、我为你好、我永远是对的、我的产品最牛、我不尴尬、不改变 | 是直播状态下的职业人设，不是真实世界观 |
| PFABES | P 痛点、F 特性、A 优势、B 利益、E 证据、S 稀缺 | FABE 的直播化扩展；顺序有硬约束 |
| 闭环 | 一段包含 F 和 B 的话术结构 | 最小闭环是 FB |
| 证据（E） | 客观第三方：数据、保障、资质、背书、真实评价 | 不是售后承诺，不是由 A 反推的好处 |
| 稀缺（S） | 真实的时间/数量/价格/赠品限制 | 是扳机，不是好感来源；提前引爆会清零好感 |
| 逼单心态 | 我懂你的痛 → 产品能解决 → 今天能占便宜 → 我坚持要你买 | 不是求人，不是操控 |

## 五、执行

| 术语 | 作者的定义 | 与常识的差异 |
|---|---|---|
| 四力 | 产品力、短视频力、直播力、供应链力 | 运营/投流不是第五力，只是放大器 |
| 执行力 | 找到问题与改变问题之间的鸿沟 | 不是「努力」，而是把方法反复做到位 |
| 四大心态陷阱 | 永远在计划、害怕失败、羡慕别人、不坚持 | 只做识别，不替代心理治疗 |
| 对标 | 人群一样、产品风格一样、IP 气质一样 | 不是「品类相同」 |
| 产品差异化 | 给真实特点起一个可传播的名字 | 原文说「就是编的」；本 skill 只允许基于真实特点的命名 |
