# 决策规则速查 — 《直播电商基础课》— 直播skill

| 能力 | 一句话规则 |
|---|---|
| 话术审计与改写：逐句分类→诊断→重写→验收 | 先逐句标七词与 PFABES，再按五层查问题，最后用同一套规则复检改写稿。 |
| 七词翻译链：需求/痛点/属性/功能/卖点/价值/买点 | 先分消费者端/产品端/商家端，再把属性→功能→价值→买点逐层翻译。 |
| PFABES 话术逻辑：六元素、闭环与三条硬规则 | 每个闭环要有 F 和 B；E 在 B 后；S 在 E 后。 |
| 购买动机与逼单：六种催化剂 + 逼单心态 | 先有价值，再选真实催化剂；每个催化剂都要给得出理由。 |
| 60 分主播：评估、七大三观与对话感训练 | 60 分 = 分享感 + 素品力 + 正能量；80 分加逻辑感；100 分加社会经历。 |
| 人货场：三面匹配与第一眼审计 | 货的外观→预设受众→演员；货的使用→场景；背书场景补信任。 |
| 八大人群：识别前三人群并调整表达 | 用城市×年龄×消费力切八类，先猜前三人群，再用平台数据核对。 |
| 短视频结构：可呈现性、三段式与单一定位 | 一秒看懂价值；一个视频一个定位；结构越简单越可批量。 |
| 直播搭建与对标：五件套与“干一样的事” | 设备/道具/场景/服饰/贴片五件套；对标要人群、产品风格、IP 气质一致。 |
| 内容诊断：传播失败、走马观花与主播没逻辑 | 先查对象，再查表达/信任/结构，最后排除流量与选品。 |
| 话术表与读稿迭代：把逻辑练成肌肉记忆 | 六列素材表→逐字稿→读10–40遍→实战→改，循环。 |
| 电商四力诊断与执行力归因 | 产品力/短视频力/直播力/供应链力；运营投流只是放大器；执行力是知道与做到之间的鸿沟。 |
| 产品差异化命名：把普通产品讲出记忆点（附合规边界） | 只给真实特点起名；解释链答不上来就是空壳。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
