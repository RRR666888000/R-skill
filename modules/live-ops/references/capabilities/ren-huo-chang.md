# 人货场：三面匹配与第一眼审计

## R — 原文 (Reading)

> “人的话主要看长相、气质、穿着。货的话看外观，看货的预设受众，再看货的使用。场的话就是你要么用背书场景，要么就用使用场景。”
>
> — 直播电商基础课，40:38–41:17

> “人货场如果说不对的话，他就是会有这种很突兀的感觉……他也是有科学理论的，叫做格式塔心理学。”
>
> — 同上，39:00–40:07

## I — 方法论骨架 (Interpretation)

人货场不是直播专属，而是短视频和直播共用的基建。它由三面组成：

- **人**：长相、气质、穿着。
- **货**：外观、预设受众、使用方式。
- **场**：使用场景或背书场景。

匹配不是靠感觉，而是有一条推导链：**货的外观 → 预设受众 → 演员的长相/气质/穿着；货的使用场景 → 拍摄/直播场景**。背书场景单独补信任，分四类：工厂（有厂=源头=便宜）、门店（有店=深耕）、科学性（研发背景、配方迭代、踩过的坑）、权威性（让人感到专业的场景，但不得冒充医院/实验室等资质）。

底层解释是格式塔：人看整体，整体不等于部分之和。观众不会逐项分析你的眉毛、眼睛、嘴，他只会觉得“哪里怪”；这个“怪”足以让他划走，而且他不需要给你理由。所以人货场要在开播/开拍前检查，而不是事后解释。

作者也给了边界：人货场不及格不等于卖不出去；它主要影响视频力。如果直播力、产品力、供应链力特别突出，仍可能起盘。

## A1 — 课程中的应用 (Past Application)

### 案例 1：婴儿车的人货场选择（课程练习，未说明实际投放结果）

- **货**：婴儿车，预设受众是宝妈/家庭。
- **人**：候选人 A 是时尚年轻女孩、微微露脐装；候选人 B 有宝妈感、家庭感。选 B。
- **场**：简约直播间（能用但效果凑合）、婴儿房（使用场景）、母婴店（背书场景）。选婴儿房或母婴店。
- **逻辑**：货的外观与预设受众决定演员；货的使用决定场景；背书场景补信任。

### 案例 2：现代人走进古装片场（课程类比）

人货场不匹配，就像现代人出现在古装拍摄现场、80 年代的人穿美团骑手服：单看每个元素都正常，放在一起就是突兀。观众不会解释为什么，只会划走。

### 案例 3：20 万场地也可能很 low（课程观点）

直播间 low 不 low 不取决于花了多少钱，而取决于协调感：背景是否整洁、人和货是否匹配、画面是否舒服。工厂、户外都能播，但不能是破墙、水管、出租屋式的背景。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要搭直播间或拍短视频，不知道场景怎么选。
2. 主播/演员与产品不搭，画面“说不上来哪里怪”。
3. 要选短视频演员，不知道看长相还是看气质。
4. 直播间想补信任，不知道用工厂、门店还是专业场景。
5. 画面点击率/进入率低，怀疑是第一眼问题。

### 语言信号

- “直播间怎么搭/场景怎么选”
- “主播穿什么/用什么人拍”
- “这个演员跟产品搭不搭”
- “人货场怎么匹配/画面很怪”
- “scene design / casting / 人货场”

### 与相邻 skill 的区分

- 与 `eight-audience-segments`：八大人群回答“对谁”，人货场回答“用什么人、货、场对她”。
- 与 `live-setup-benchmarking`：人货场是匹配逻辑；搭建五件套是设备、道具、贴片、对标等执行清单。
- 与 `short-video-structure`：人货场决定画面是否可信；结构决定内容怎么排。

## E — 可执行步骤 (Execution)

**输入契约**：一款货、目标人群、可选的演员与场地。缺目标人群时先做 `eight-audience-segments`。

1. **描述货**
   - 外观、价格、预设受众、使用方式。
   - 完成标准：能说清“这货一看是给谁用的”。

2. **推导人**
   - 按预设受众选长相、气质、穿着。
   - 完成标准：演员与货放在同一画面，不需要解释。

3. **选场**
   - 优先使用场景；需要信任时加背书场景（工厂/门店/科学性/权威性）。
   - 完成标准：场景能回答“为什么在这里卖这东西”。

4. **做整体检查**
   - 把货、人、场放进同一画面，找一个没听过解释的外部人看 3 秒。
   - 完成标准：对方说“协调/舒服”，而不是“说不上来哪里怪”。

5. **一次只改一个变量**
   - 不协调时，按货→人→场的顺序调整；每次只改一项，再看效果。
   - 完成标准：能定位到具体不匹配的元素。

6. **记录与复用**
   - 把通过的组合写成模板（人设、服装、场景、道具）。
   - 完成标准：下次拍同品类能直接复用，不用重新试。

**输出契约**：一张人/货/场匹配表 + 一张场景选择表（使用场景/背书场景/普通直播间）+ 一次外部人 3 秒测试记录。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 纯 IP/口播/知识类账号：人货场的“货”很弱，重点在人与内容。
- 产品本身没有明确使用场景：先补产品定义，不要硬搭场景。
- 预算极低时：优先整洁、协调，不要租昂贵但不匹配的场地。

### 作者警告的失败模式

- 人货场不匹配：时尚女孩配婴儿车、破墙配高客单。
- 只靠花钱堆场景：20 万场地也可能很 low。
- 背书场景造假：冒充医院、实验室、检测机构，可能误导消费者。
- 把“普通直播间”当万能：能用，但效果通常只是凑合。

### 作者盲点 / 时代局限

- 人货场不是唯一变量；产品力、直播力、供应链力可能盖过它。
- “协调感”没有量化标准，依赖审美与经验。
- 课程对不同类目（食品、美妆、服饰、家居）的场景差异没有展开。

### 容易混淆的邻近方法论

- `live-setup-benchmarking`：搭建是清单，人货场是匹配逻辑。
- `eight-audience-segments`：人群是输入，人货场是呈现。
- `short-video-structure`：结构解决“怎么讲”，人货场解决“画面可不可信”。
