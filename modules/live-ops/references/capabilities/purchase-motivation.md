# 购买动机：六种催化剂与逼单心态

## R — 原文 (Reading)

> “购买动机它分为催化剂型购买动机和理由型购买动机。催化剂型分为六个，价格保障、紧迫、信任、从重、急需，也就意味着他为什么要现在去买。”
>
> — 直播电商基础课，07:16–07:47

> “正确的逼单心态应该是我懂你的痛处，我确定我的产品能解决你眼下的麻烦，而且我明知今天能让你占到便宜，所以我希望你当下来买我的产品。”
>
> — 同上，13:09

## I — 方法论骨架 (Interpretation)

购买动机分两层：理由型回答“为什么需要”（痛点、价值），催化剂型回答“为什么现在买”（价格、保障、紧迫、信任、从众、急需）。作者日常只让学员记催化剂型，把买点简化为“价值 + 催化剂型购买动机”；理由型用来判断需求是否成立。这个简化与原课的另一句“完整购买动机也包含痛点、价值”存在口径张力，能力卡采用简化式，并在边界里说明。

六项催化剂不是六个词，而是六种可落地的动作：

- **价格**：今天买更便宜；必须给“为什么今天便宜”的理由。
- **保障**：运费险、试用小样、七天无理由，降低试错成本。
- **紧迫**：只剩几单、不补单、马上下播；同样要给理由。
- **信任**：保障 + 背书（资质、证书、荣誉）+ 主播气质（不油、不套路、有底气）。
- **从众**：真实的热销/评价/公屏氛围；作者原文提到水军，但那是失败模式，不是可执行建议。
- **急需**：把产品概念升维，从“可有可无”变成“我很需要”（笔记本=自我提升，枕头=生活质量/颈椎）。

逼单不是求人。正确的心态是：我懂你的痛 → 我确定产品能解决 → 我知道今天能让你占便宜 → 所以我坚持要你买。若产品根本不匹配，这套心态不成立，不能硬逼。

## A1 — 课程中的应用 (Past Application)

### 案例 1：速干衣的买点（课程演示，未说明销售结果）

价值句之后加“今天拍立减 30、前 500 个送冰袖”。作者把这两个动机归为“价格 + 紧迫”，并强调：价格只有今天有，必须给“为什么今天有”的理由。

### 案例 2：笔记本与枕头的升维（课程演示，未说明结果）

笔记本不是“办公用品”，而是“自我提升”；枕头不是“睡觉用的”，而是“提高生活质量、缓解颈椎病”。这是“急需”催化剂：把产品抬到更高、更严重的维度，让消费者发现“我不是可有可无，我是很需要”。

### 案例 3：逼单心态的反向检验（课程观点，未给数据）

如果产品真能解决麻烦、今天真能占便宜，却不让他买，等于放弃帮他；反过来，如果产品不匹配，再热情也不该逼。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户已经理解产品价值，但迟迟不下单。
2. 主播不敢逼单，觉得“求人买东西很羞耻”。
3. 直播间转化率低，需要设计“现在买”的理由。
4. 做活动/大促，不知道怎么组合价格、保障、紧迫、信任。
5. 团队只会喊“321 上链接”，没有动机设计。

### 语言信号

- “怎么让用户现在就买/怎么逼单”
- “主播不敢促单/觉得逼单丢人”
- “转化率低/临门一脚不行”
- “限时活动怎么说/怎么设计紧迫感”
- “closing / urgency / conversion / 逼单话术”

### 与相邻 skill 的区分

- 与 `seven-word-translation`：七词链解决“为什么需要”（价值），本 skill 解决“为什么现在买”。
- 与 `pfabes-scripting`：本 skill 设计 S 的内容与真实性；PFABES 规定 S 必须放在 E 之后。
- 与 `host-60-score`：本 skill 是成交设计；主播状态与表达是另一层。

## E — 可执行步骤 (Execution)

**输入契约**：产品、目标人群、已成立的价值句、真实可用的活动/保障/背书。缺真实动机时，不要进入第 3 步。

1. **先确认需求成立**
   - 问：目标人群是否认可痛点与价值？
   - 判停：不认可 → 回到 `seven-word-translation`，不要直接上催化剂。

2. **盘点真实动机**
   - 逐项检查：价格、保障、紧迫、信任、从众、急需。
   - 完成标准：每一项都标注“有真实依据 / 没有 / 需要补”。

3. **给每个动机配理由**
   - 价格：为什么今天便宜（活动、清仓、节点）。
   - 紧迫：为什么只剩这些（库存、排期、下播）。
   - 信任：保障条款、资质、真实评价、主播表现。
   - 完成标准：理由能被消费者追问一次而不崩。

4. **写催化剂话术**
   - 每项 1–2 句，短、具体、可验证。
   - 完成标准：不出现虚构原价、假库存、假倒计时、假水军。

5. **重构逼单心态**
   - 按“我懂你的痛 → 产品能解决 → 今天能占便宜 → 我坚持要你买”说一遍。
   - 完成标准：主播能自然说出，不心虚；若心虚，回到第 2 步检查产品是否真的匹配。

6. **接入 PFABES**
   - 把催化剂放在 E 之后作为 S；E 没讲完不逼单。
   - 完成标准：每段逼单前，都有一句客观证据。

**输出契约**：一张六催化剂表（动机/真实依据/话术/风险）+ 一段 30–60 秒逼单话术 + 一句“如果产品不匹配就不逼”的自检。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 产品与人群不匹配：先换品/换人群，不要用话术硬逼。
- 没有真实活动/保障：不要编造稀缺与优惠。
- 高客单、长决策产品：一次逼单不够，需要多次触达与证据积累。
- 平台明确禁止的诱导行为：遵守平台规则与消费者权益保护法。

### 作者警告的失败模式

- 价格/紧迫不给理由：消费者不信。
- 把逼单当求人：语气虚、动作变形。
- 只靠水军带节奏：主播被公屏带跑，信任反噬。
- 说完卖点直接逼单：消费者还没感到与自己有关。
- 过度贩卖焦虑：尤其涉及健康、儿童、老人。

### 作者盲点 / 时代局限

- 原文把“水军”列为从众手段，这在真实经营中可能构成虚假宣传；本卡只保留“真实热销/评价”的版本。
- “逼单是帮人”的心态容易被滥用；如果产品不匹配，越真诚越有害。
- 六催化剂的有效性依赖类目、价格带、流量结构；课程没有给对照数据。

### 容易混淆的邻近方法论

- `seven-word-translation`：价值是“为什么需要”，不是“为什么现在买”。
- `pfabes-scripting`：S 的位置规则比 S 的内容更重要；提前引爆会清零好感。
- `host-60-score`：主播的正能量/底气会影响信任，但不等于成交设计。
