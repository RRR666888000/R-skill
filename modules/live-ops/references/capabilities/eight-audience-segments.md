# 八大人群：识别前三人群并调整表达

## R — 原文 (Reading)

> “八大人群很多人其实到现在都没区分开来……其实实际上就是三个，一个是城市，一个是年龄，一个是消费力。”
>
> — 直播电商基础课，15:20–15:38

> “蓝领、白领这些永远都是看消费等级，而不是看薪水。如果你很高薪，但是你就是不爱花钱，大几率它也是会被切进蓝领的。”
>
> — 同上，36:03–36:51

## I — 方法论骨架 (Interpretation)

八大人群不是“八种性格”，而是平台用三个轴切出来的策略人群：城市（三线及以上 / 四线及以下）、年龄、消费力。都市系六类：Z 世代、新锐白领、精致妈妈、资深中产、都市蓝领、都市银发；小镇系两类：小镇青年、小镇中老年。

每个人群按六个维度描述：是谁、消费 DNA、典型品类、购物习惯、心理动机、反感什么。人群会流动：都市小孩=Z 世代，非都市=小镇青年；Z 世代长大，留大城市且爱花钱=新锐白领，不爱花钱=都市蓝领，回县城=小镇青年；新锐白领女性已婚已育/备孕=精致妈妈；保住中高消费力到 36–50 岁=资深中产；新锐白领/都市蓝领变老=都市银发；小镇青年变老=小镇中老年。

关键判断：**蓝领/白领按消费等级划分，不按薪水**；挣得多不等于花得多。八大人群是策略人群，不是全世界，也不是个体决定论；平台口径会变，作者自己说“不可能是百分之百绝对正确”。

用法不是背标签，而是：先猜账号的前三人群 → 用平台数据核对 → 对猜错的归因（产品？短视频？人物形象？）→ 调整直播画风、短视频风格、讲话方式。作者给的经验合格线是“三个中两个”。

## A1 — 课程中的应用 (Past Application)

### 案例 1：老钱风男装的对标判断（课程演示，未给后台数据）

两个直播间都卖老钱风男装，但主播气质和 IP 导向不同：一个偏新锐白领，一个偏资深中产。作者提醒：不能只看“卖一样的东西”，要看人群是否一样、产品风格是否一样、IP 气质是否一样；否则会学错对象。

### 案例 2：电视剧人物记忆法（课程演示）

Z 世代：方一凡、乔英子、姜小果、段家宝；新锐白领：王漫妮、唐颖、樊胜美、李思思、安迪；精致妈妈：顾佳、田雨岚、南俪、沈慧星；小镇青年：朱朝阳、谢之遥、马得福、白麦苗；资深中产：方圆、董文洁；都市银发：苏大强；都市蓝领：周晓勤、张光正、周炳坤；小镇中老年：刘能、谢广坤、王响。仅作记忆辅助，人物带有时代与地域刻板印象。

### 案例 3：前三人群训练（课程方法，未给准确率数据）

看同行账号，先猜前三人群，再查真实数据，对比命中率；猜错就归因“我为什么想错、它为什么呈现这种分布”。三个中两个即“大差不差”。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 不知道自己的账号/产品主要卖给谁。
2. 要选品、定价、定直播画风，需要先定人群。
3. 投流/千川/云图人群包不知道怎么选。
4. 看对标只看品类，结果学错对象。
5. 团队对“精致妈妈/新锐白领/小镇青年”各说各话。

### 语言信号

- “我的账号人群是谁/前三人群是什么”
- “八大人群怎么分/我属于哪个人群”
- “投流人群怎么选/云图人群包”
- “这个品适合卖给谁”
- “audience segmentation / target audience / 八大人群”

### 与相邻 skill 的区分

- 与 `ren-huo-chang`：八大人群回答“对谁”，人货场回答“用什么人、货、场对她”。
- 与 `short-video-structure`：人群决定内容选题与表达，结构决定怎么拍。
- 与 `live-setup-benchmarking`：人群是筛对标的必要条件，不是全部。

## E — 可执行步骤 (Execution)

**输入契约**：产品品类、价格带、风格、主播/账号形象；有后台数据就一并提供。没有数据时，明确标记为“假设”，不要当结论。

1. **列三轴**
   - 城市层级、年龄、消费力。
   - 完成标准：每一项都有依据（产品、价格、内容、主播形象），不是拍脑袋。

2. **提出前三人群假设**
   - 从八类里选 3 个，按可能性排序。
   - 完成标准：每个都能说出“为什么是她/他”。

3. **填六维画像**
   - 是谁、消费 DNA、典型品类、购物习惯、心理动机、反感什么。
   - 完成标准：每一维都能对应到具体的表达动作（场景、话术、选品）。

4. **用数据核对**
   - 查平台后台/云图的前三人群；算命中率。
   - 完成标准：三中二为经验合格；连续偏离就重建假设。

5. **归因偏差**
   - 猜错时问：是产品、短视频、人物形象，还是价格导致？
   - 完成标准：至少给出一个可验证的原因和一次调整实验。

6. **调整表达**
   - 场景、服饰、语速、用词、促销方式按人群改。
   - 完成标准：改动能在直播/短视频里被看见，不只是写在纸上。

**输出契约**：一张前三人群表（人群/依据/六维/表达动作/待核对数据）+ 一份 2 周验证计划。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 没有产品/内容/价格信息时，不要凭空贴人群标签。
- 不要用人群标签替代真实用户访谈与后台数据。
- 不要用地域、年龄、性别做歧视性判断；人群是策略工具，不是偏见许可证。
- 平台口径变化时，先核对当前定义。

### 作者警告的失败模式

- 把 Z 世代等同于所有年轻人。
- 把蓝领/白领按薪水划分，而不是消费等级。
- 认为资深中产是新锐白领的必经之路。
- 八大人群之外的人被忽略；35/36、50 岁边界有重叠。
- 只看品类相同就对标，不看人群是否一样。

### 作者盲点 / 时代局限

- 八大人群是平台策略人群，不是心理学分类；会随平台、类目、时间变化。
- 课程没有给后台取数路径、数据更新时间、样本量。
- 人群标签会自我强化：投流越精准，越容易看不到潜在人群。

### 容易混淆的邻近方法论

- `ren-huo-chang`：人群是“对谁”，人货场是“怎么呈现”。
- `live-setup-benchmarking`：对标要人群一致，但人群一致不等于可以照抄。
