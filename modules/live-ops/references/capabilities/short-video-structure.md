# 短视频结构：可呈现性、三段式与单一定位

## R — 原文 (Reading)

> “一个视频就一个主定位。这个主定位会占到整个短视频 70% 到 80% 的内容。然后其他零散的一些价值点可能只占到 20% 和 30，这就叫短视频的 28 理论。”
>
> — 直播电商基础课，57:50–58:36

> “我们说的这个可呈现性到底呈现产品什么东西？呈现的一定是价值，而不是呈现卖点。”
>
> — 同上，52:51–53:11

## I — 方法论骨架 (Interpretation)

短视频不是“拍得好看”，而是“让观众一秒看懂这东西跟我有什么关系”。这由两件事决定：

1. **可呈现性**：产品本身有没有肉眼可辨的特点；呈现方式能不能让观众一秒看懂。金子涂成钢色，再讲材料也没用——不可呈现；功能型产品优先升级能拍出来的功能，而不是堆不可见的材质。
2. **结构**：开头 + 产品呈现 + 引导行动。可以拍三段式，也可以两段式、一段式；越简单越可批量。开头不靠创意，靠素材流：每天追同行、保持高网速冲浪、跨品类迁移爆款、每天刷 1 小时短视频积累。

最关键的是 **28 理论**：一条视频只打一个主定位，主定位占 70–80%，其他零散价值点占 20–30%。多合一只是产品事实，一个标签才是心智事实；消费者看完能说出一个词，才算打进去。

两种“走马观花”要区分：客观型是一个卖点接一个卖点，堆了很多；消费者感知型是主定位很大（如“立得稳”），但每个论据没有让消费者联想到与主定位相关。后者更隐蔽，商家自己往往看不见。

## A1 — 课程中的应用 (Past Application)

### 案例 1：手机支架“立得稳”（课程演示，未说明销售结果）

主定位是“立得稳”。论据有三个：底盘用材好、支架磁吸、连接柱用材没问题。作者提醒：如果消费者不能把其中任何一个论据接回“立得稳”，这条视频在消费者看来就是走马观花。正确做法是让每个论据都能被消费者接回主定位。

### 案例 2：六合一蓬松水（课程演示，未说明销售结果）

产品是六合一：蓬松水、发泥、发胶、护发精油、控油精油、香水。作者买过，但只记住“蓬松水能定型”。结论：多合一只是产品的事实，一个标签才是心智的事实；消费者只会替你选一个词记住。

### 案例 3：2000 元/天场地只拍 10 条（课程演示）

场地一天 2000 元，产出只能发 10 条，最多用两天；如果一个月租半个月，成本不可行。这是“可执行性预检”：场地、脚本难度、创意要求、品牌基因，任何一项让团队无法稳定产出，就要降级方案。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 不知道短视频拍什么、怎么开头。
2. 一条视频想讲很多卖点，结果什么都没记住。
3. 产品很好，但拍出来观众看不懂。
4. 团队拍得花里胡哨，产量低、不可持续。
5. 视频有播放没转化，怀疑定位不清。

### 语言信号

- “短视频怎么拍/脚本怎么写”
- “开头怎么抓人/前 3 秒”
- “一个视频讲几个卖点”
- “产品拍不出来/观众看不懂”
- “short video script / hook / positioning / 28 理论”

### 与相邻 skill 的区分

- 与 `seven-word-translation`：七词链产出价值句；本 skill 决定用哪个价值句当主定位、怎么拍。
- 与 `pfabes-scripting`：PFABES 是直播话术结构；短视频结构更短、更依赖画面。
- 与 `host-60-score`：本 skill 管内容结构；主播/演员表现是另一层。
- 与 `ren-huo-chang`：人货场决定画面可信度；本 skill 决定内容顺序。

## E — 可执行步骤 (Execution)

**输入契约**：产品、目标人群、一个想打的定位、可拍摄的场景与演员。缺定位时先做 `seven-word-translation` 选出核心价值。

1. **定一个主定位**
   - 只选一个词/一句话（如“立得稳”“不粘身”“送礼有面子”）。
   - 完成标准：能一句话说完，不需要“以及”。

2. **做可呈现性双检**
   - 产品特点能否被肉眼看见？呈现能否一秒看懂？
   - 完成标准：找一个没听过解释的人看 1 秒，能说出“这东西对我有什么用”。
   - 判停：不能 → 换特点、换拍法，或换产品。

3. **选结构**
   - 默认三段式：开头（钩子）+ 产品呈现（价值）+ 引导行动。
   - 团队弱时用两段式/一段式。
   - 完成标准：团队能按周稳定产出，不依赖某个人的创意。

4. **分配 28**
   - 主定位占 70–80%，其他价值点占 20–30%。
   - 完成标准：删掉所有不能回扣主定位的论据。

5. **准备开头素材**
   - 每天追同行、刷热点、跨品类迁移、积累 1 小时/天。
   - 完成标准：有 5 条可替换的开头模板，不临时想。

6. **做可执行性预检**
   - 算场地成本/产出条数、脚本难度、是否需要专人、品牌基因是否匹配。
   - 完成标准：任何一项不可持续，就降级方案。

7. **外部测试**
   - 让身边人看一遍，问“你记住了什么/这东西对你有什么用”。
   - 完成标准：能说出主定位；说不出来就重剪。

**输出契约**：一条 15–60 秒脚本（含开头/价值呈现/行动引导）+ 分镜或拍摄清单 + 外部测试记录 + 主定位占比说明。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 强 IP、剧情号、矩阵号：不一定适用“一个视频一个定位”。
- 品牌形象片、长视频：结构不同，不能硬套 15–60 秒。
- 产品本身无可呈现差异：先改产品/包装/演示方式，不要靠剪辑造假。

### 作者警告的失败模式

- 卖点堆砌、走马观花：什么都讲了，等于什么都没说。
- 一个视频多个定位：消费者什么都记不住。
- 花里胡哨、不可批量：团队拍不出来，方向失误。
- 只讲参数不讲价值：观众不知道与自己有什么关系。
- 创作者自嗨：自己看有滤镜，必须让外部人测试。

### 作者盲点 / 时代局限

- 28 理论的比例是经验值，没有对照数据；不同类目、不同账号阶段可能不同。
- 课程默认“简单结构+数量”能跑出结果，但选品、流量、价格仍是更大的变量。
- 对剧情、IP、矩阵、直播切片等形态没有展开。

### 容易混淆的邻近方法论

- `seven-word-translation`：解决“说什么价值”，不解决“怎么拍”。
- `pfabes-scripting`：直播话术可以长、可以循环；短视频必须短、单点。
- `ren-huo-chang`：画面匹配不等于内容结构。
