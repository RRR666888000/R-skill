# 60 分主播：评估、七大三观与对话感训练

## R — 原文 (Reading)

> “第一个就是分享感……第二个是素品力……第三个就是正能量……能够再强一点的主播，就是在这个基础上面再加到一个逻辑感。”
>
> — 直播电商基础课，1:37:50–1:39:01；1:54:41

> “七大核心的三观。第一有分享感，第二正能量，第三我为你好，第四我永远是对的，第五我的产品最牛，第六我不尴尬，第七不改变。”
>
> — 同上，1:39:01–1:42:41

## I — 方法论骨架 (Interpretation)

60 分主播不是“会喊会演”，而是三项基本功齐备：

1. **分享感**：像正常人说话，不像机器人；直播也要有对话感。
2. **素品力**：持续讲 FB——产品有什么 + 给消费者什么好处；30–40 秒内必须出现一次，一分钟没有就是严重问题。
3. **正能量**：热爱行业、热心解决问题；不等于音量大小，沉稳、幽默、老实本分都可以是正能量。

在 60 分之上，加“逻辑感”到 80 分，再加“社会经历”到 100 分。分数是经验刻度，不是行业标准。

七大核心三观是开播前的职业人设：有分享感、正能量、我为你好、我永远是对的、我的产品最牛、我不尴尬、不改变（不被公屏带节奏）。作者明确说，三观不是真实世界观，而是直播状态下的职业人设；它可以通过刻意训练建立。这里必须加一道边界：**“我永远是对的/我的产品最牛”是给自己底气，不是用来向消费者虚构事实**。

主播没逻辑有三个原因：直播走神且放任、开启省电模式靠惯性说话、没有受过逻辑训练。前两个是态度问题，第三个用 PFABES 训练。复盘要用逐字稿指认具体句子（“你 8 分钟只有 30 秒素品”），不要说“状态好一点”。

对话感可以练：穿透法（真安排一个人站在相机后对话，熟练后撤掉）、和世界万物说话（宠物、玩偶）、想象镜头背后是一个个真人；前置心态是脱敏，放下“很多人在看我”的偶像包袱。

## A1 — 课程中的应用 (Past Application)

### 案例 1：枕头主播（课程认定的 60 分样板，未给转化数据）

作者认为该主播达到 60 分：讲话有分享感、像正常人对话；持续素品，讲纤维、支撑性、回弹力、使用年限；有信任背书（销量、复购、榜单、原材料合同）；有逼单（最后 12 分钟、四点钟下播、今天发货）。作者用这个案例说明：60 分不是不逼单，而是三项基本功都在。

### 案例 2：0 分主播（课程认定的反面案例，未给数据）

全程“欢迎、感谢、早拍早发、早拍早享受”，排比句、口水话、吐字粘连；一分钟内没有任何素品；没有正能量。作者给 0 分。20 分版本是“声音很大、很有正能量，但没有分享感、没有素品”。

### 案例 3：英语课主播（课程认定的 80–100 分案例，未给数据）

风格夸张，但讲到产品时条理清晰；每句话都指向某个行为（互动、逼单、流量）。作者提醒：可学的是目的性，不是夸张本身；“吴彦祖在机场等/要退休”这类话术本身不真实，不应照抄。

### 案例 4：狼人杀警长牌（课程类比，用来说明信念感）

一个人坚信自己是警长，尽管牌已被抽走，他理直气壮到让真警长怀疑自己。作者用它说明：主观相信会影响表达底气。但这也正是伦理边界所在：底气可以练，事实不能编。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 不知道一个主播行不行，想评估/面试/复盘。
2. 主播讲话像机器人、没有分享感、不敢播。
3. 主播长时间不讲产品，只会欢迎感谢。
4. 主播状态差、被公屏带跑、说错话就慌。
5. 想给主播做训练计划，不知道从哪一项开始。

### 语言信号

- “这个主播行不行/能打几分”
- “主播培训/主播复盘/主播没状态”
- “主播像机器人/不敢播/讲话没逻辑”
- “60 分主播/七大三观/分享感/素品力”
- “host evaluation / livestream host training”

### 与相邻 skill 的区分

- 与 `pfabes-scripting`：本 skill 评估“人”的状态与基本功；PFABES 提供“话”的结构与素材。
- 与 `eight-audience-segments`：本 skill 不判断对谁讲，只判断讲的人是否合格。
- 与 `purchase-motivation`：逼单心态是成交设计；本 skill 是主播整体状态。

## E — 可执行步骤 (Execution)

**输入契约**：一段 15 分钟直播回放（或短视频素材）、主播背景、账号阶段。没有回放时，先录一段再评。

1. **看回放，逐项打分**
   - 分享感：像正常人说话吗？
   - 素品力：30–40 秒内有没有 FB？最长空档多久？
   - 正能量：有没有热情/职业操守？是否半死不活？
   - 完成标准：三项各有具体句子作证据，不写“感觉还行”。

2. **判 60 分**
   - 三项齐 = 60 分；缺一 = 未达标；0 分 = 口水话+无素品+无正能量。
   - 完成标准：能指出缺的是哪一项、从第几秒开始。

3. **诊断逻辑**
   - 走神？省电模式？没受过训练？
   - 完成标准：归到一类，并决定是态度谈话还是方法训练。

4. **练对话感**
   - 三选一：穿透法、和世界万物说话、想象镜头后是人；前置脱敏。
   - 完成标准：回放听起来像在打视频电话，没有直播腔。

5. **装七大三观**
   - 开播前逐条自检：分享感、正能量、我为你好、我永远是对的、我的产品最牛、我不尴尬、不改变。
   - 完成标准：能在直播中稳定演出来；同时守住“不虚构事实”的底线。

6. **用逐字稿复盘**
   - 截 15 分钟回放，扒逐字稿，标 PFABES，量最长无素品间隔。
   - 完成标准：反馈落到具体句子；素品间隔回到 30–40 秒内。

7. **升级**
   - 60 分后加逻辑感（PFABES）到 80；再加社会经历/案例到 100。
   - 完成标准：下一场只改一个项，不一次改全部。

**输出契约**：一张 60 分评分表（三项/证据句/得分/训练项）+ 一份 2 周训练计划 + 一次逐字稿复盘记录。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 账号起不来是产品/流量/价格问题：不要先怪主播。
- 主播只是短视频流量的承接工具人：能卖货不等于主播 60 分，反之亦然。
- 需要专业心理干预/职业倦怠：本 skill 不是心理咨询。

### 作者警告的失败模式

- 只喊不素品：一分钟没有 FB，流量接不住。
- 像机器人/背稿：没有分享感。
- 半死不活/抱怨：没有正能量。
- 被公屏带节奏：不改变、不控场。
- 说错话就慌：不尴尬、我永远是对的（指状态，不是事实）。

### 作者盲点 / 时代局限

- 60/80/100 分没有权重、评分细则、对照数据；“社会经历”没有训练法。
- “给自己洗脑、骗过很多人”只能用于建立底气，不能用于虚构产品事实；本卡把它降级为“职业信念”，并加合规边界。
- 正能量不等于高音量；不同风格（沉稳、幽默、老实）都可能是正能量。
- 课程对主播的体力、嗓音、心理压力没有讨论。

### 容易混淆的邻近方法论

- `pfabes-scripting`：话术逻辑是 80 分项，不是 60 分门槛。
- `purchase-motivation`：逼单心态是成交设计，不是主播全部状态。
- `four-force-diagnosis`：主播只是直播力的一部分，不能解释所有起盘问题。
