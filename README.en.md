# Lingjiang Skill

[中文](README.md)

Lingjiang Skill (`lingjiang-content`, version 0.9.0) is an agent skill for short-video creation, Soul Questions, and live-commerce operations.

## Short video

Compare angles, build an outline, and write, revise, or audit a single video when asked.

## Soul Questions

Say “灵魂问答” to walk the six groups one at a time for content research and acquisition analysis.

## Live operations

Live-selling blockers — closing, scripts, product rounds, retention, the host, viewers, conversion, PFABES, the seven-word split — open the live-ops module. “开启凌酱直播运营skill” does the same.

## Install

```bash
npx skills add RRR666888000/R-skill
```

## Update

```bash
npx skills update lingjiang-content
```

Requires Node.js 22.20 or later. See [install notes](docs/INSTALL.md).

## How to trigger

- “帮我想几个选题，再推荐一个骨架。”
- “陪我走一轮灵魂问答，先做内容调研。”
- “用户老说再看看，怎么逼单？”
- “开启凌酱直播运营skill。”
